# Nieuwe methode

Een Vite-website met de installatie-instructies voor de nieuwe methode.

## Lokaal starten

Installeer Node.js en voer daarna in deze map uit:

```bash
npm install
npm run dev
```

Open het adres dat Vite toont. Voor een productieversie:

```bash
npm run build
```

De bestanden voor publicatie staan dan in de map `dist`.
